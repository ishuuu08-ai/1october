# Boyfriend's Day ❤️

A two-slide romantic mini website made for GitHub Pages.

## Files
- `index.html`
- `style.css`
- `assets/` — 15 photos

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and the entire `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your `main` branch and `/ (root)`.
6. Save and wait for GitHub to give you the website link.

The site is designed for phones and uses no external JavaScript libraries.

### Music
The supplied song is included as `assets/song.mp3`. It starts when the visitor taps **Open my heart**, which works around mobile browser autoplay restrictions.
